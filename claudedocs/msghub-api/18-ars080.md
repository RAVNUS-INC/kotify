# 5.1 080 수신거부
> 원문: https://doc.msghub.uplus.co.kr/rest-api/05부가서비스/0501ars080/ · 확인일 2026-10-16

## 한눈에 보기

인증은 다른 API 와 달리 `Authorization` 토큰이 아니라 `apiKey` 헤더를 쓴다.

| 기능 | Method | 경로 | 호스트 |
|---|---|---|---|
| 수신거부 번호 등록 | POST | `/client/v1/080/ars080Reject` | api |
| 수신거부 번호 목록 조회 | POST | `/client/v1.2/080/ars080RejectList` | mnt-api |
| 수신거부 번호 삭제 | DELETE | `/client/v1/080/ars080RejectDelete` | api |
| 수신거부 번호 기간 조회 | GET | `/client/v1.1/080/ars080BlockNumberList` | mnt-api |

## 수신거부 번호 등록

`POST /client/v1/080/ars080Reject`

수신거부 번호를 한 번에 여러 개 등록한다. 등록 즉시 적용된다.

| 구분 | 필드 | 타입 | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| Header | apiKey | String | ● | - | API 인증 키 |
| Body | phone | String | ● | 최대 20 | 수신거부할 전화번호 |
| Body | callback | String | ● | 최대 20 | 발신번호. `*` 이면 모든 발신번호에 적용 |

요청 예시 (Body 는 배열)

```json
[
  { "phone": "01000000001", "callback": "15440000" },
  { "phone": "01000000002", "callback": "*" }
]
```

응답 예시

```json
{ "code": "10000", "message": "성공" }
```

> 주의
> - 같은 수신번호+발신번호 조합은 중복 등록할 수 없다.
> - 별도 확인 절차 없이 즉시 수신거부가 적용된다.
> - 원문 확인 필요: 필드 표는 단일 객체처럼 쓰여 있으나 예시는 배열이다. 여러 건 등록이 배열 Body 라는 점은 예시 기준 추정.

## 수신거부 번호 목록 조회

`POST /client/v1.2/080/ars080RejectList`

등록된 번호를 페이지 단위로 조회한다. 삭제된 번호도 포함된다.

| 구분 | 필드 | 타입 | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| Header | apiKey | String | ● | - | API 인증 키 |
| Query | phone | String | - | - | 특정 번호만 조회 |
| Query | listCnt | Integer | ● | - | 페이지당 조회 건수 |
| Query | pageIdx | Integer | ● | - | 페이지 번호 (1부터) |

응답 data

| 필드 | 타입 | 설명 |
|---|---|---|
| data.listCnt | Integer | 페이지당 조회 건수 |
| data.pageIdx | Integer | 현재 페이지 |
| data.totalCnt | Integer | 전체 조회 건수 |
| data.rejectList[].phone | String | 수신거부 전화번호 |
| data.rejectList[].aniNumber | String | 수신거부를 요청한 발신번호 (수신거부번호와 다를 때 표기) |
| data.rejectList[].callback | String | 발신번호 |
| data.rejectList[].delYn | String | 삭제 여부 (Y/N) |
| data.rejectList[].updDt | String | 최종 수정 일시 (예시: `2023-06-15 14:30:00`) |
| data.rejectList[].delDt | String | 삭제 일시 (null 가능) |

요청 예시 (Query 로만 전달, Body 없음)

```
POST https://mnt-api.msghub.uplus.co.kr/client/v1.2/080/ars080RejectList?phone=01000000001&listCnt=10&pageIdx=1
```

응답 예시

```json
{
  "code": "10000", "message": "성공",
  "data": {
    "listCnt": 10, "pageIdx": 1,
    "rejectList": [
      { "phone": "01000000001", "callback": "", "aniNumber": "01000000002",
        "delYn": "N", "updDt": "2023-06-15 14:30:00", "delDt": null }
    ],
    "totalCnt": 1
  }
}
```

> 주의
> - mnt-api 호스트를 쓴다.
> - 원문 확인 필요: 본문 URL 은 `/client/v1.2/...` 인데 curl 예시는 `/client/v1/...` 이다. v1.2 를 기준으로 적었다.
> - `listCnt` 상한은 원문에 없고 "시스템 성능을 고려해 적절히" 설정하라고만 되어 있다.

## 수신거부 번호 삭제

`DELETE /client/v1/080/ars080RejectDelete`

등록된 수신거부를 해제한다.

| 구분 | 필드 | 타입 | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| Header | apiKey | String | ● | - | API 인증 키 |
| Body | phone | String | ● | 최대 20 | 삭제할 수신번호 |
| Body | callback | String | ● | 최대 20 | 삭제할 발신번호 |

요청 예시

```json
{ "phone": "01000000001", "callback": "15440000" }
```

응답 예시

```json
{ "code": "10000", "message": "성공" }
```

> 주의
> - 즉시 적용되고 복구할 수 없다.
> - 이미 삭제된 번호를 다시 삭제해도 성공으로 처리된다.
> - `callback` 을 `*` 로 보내면 해당 수신번호의 모든 발신번호 수신거부가 해제된다.

## 수신거부 번호 기간 조회

`GET /client/v1.1/080/ars080BlockNumberList`

기간(등록 시각 기준으로 보임)별 수신거부 번호 목록.

| 구분 | 필드 | 타입 | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| Header | apiKey | String | ● | - | API 인증 키 |
| Query | 080ArsNumber | String | ● | 최대 20 | 080 ARS 차단(수신거부) 번호 |
| Query | fromTime | String | ● | - | 시작 일시 `YYYYMMDDHHMMSS` |
| Query | toTime | String | ● | - | 종료 일시 `YYYYMMDDHHMMSS` |
| Query | page | Number | - | - | 페이지 번호, 기본 1 |
| Query | pageSize | Number | - | 최대 300 | 페이지 크기, 기본 10 |

응답

| 필드 | 타입 | 설명 |
|---|---|---|
| data[].blockNumber | String | 수신거부번호 |
| data[].aniNumber | String | 수신거부를 요청한 발신번호 (수신거부번호와 다를 때 표기) |
| data[].updateTime | String | 등록일자 (예시: `2024-09-06 14:06:45`) |
| data[].status | String | `active` / `inactive` |
| meta.totalItems | Integer | 전체 건수 |
| meta.totalPages | Integer | 전체 페이지 수 |
| meta.080ArsNumber | String | 080 차단 번호 |
| meta.fromTime | String | 검색 시작 일시 |
| meta.toTime | String | 검색 종료 일시 |
| meta.pageSize | Integer | 페이지 크기 |
| meta.page | Integer | 현재 페이지 |

응답 예시

```json
{
  "code": "10000", "message": "성공",
  "data": [
    { "blockNumber": "01000000001", "aniNumber": "01000000002", "updateTime": "2024-09-06 14:06:45", "status": "active" },
    { "blockNumber": "01000000003", "aniNumber": "01000000002", "updateTime": "2024-09-06 14:06:45", "status": "inactive" }
  ],
  "meta": { "totalItems": 15, "totalPages": 2, "080ArsNumber": "08000000000",
            "fromTime": "20240901000000", "toTime": "20240930000000", "pageSize": 10, "page": 1 }
}
```

> 주의
> - mnt-api 호스트를 쓴다.
> - `status`: `active` 는 번호가 삭제되어 차단이 아닌 상태, `inactive` 는 차단 중이라는 뜻이다(이름과 반대처럼 보이니 주의).
> - 응답에 공통 `data` 외에 `meta` 가 따로 온다.
